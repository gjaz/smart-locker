# SmartLocker

Sistema de gestión de lockers inteligentes desarrollado como proyecto de aprendizaje y portafolio profesional.

## Tecnologías

- Angular 22
- TypeScript
- Angular Router
- Reactive Forms
- Git
- GitHub

## Funcionalidades actuales

- Dashboard
- Navegación mediante Angular Router
- Gestión de lockers
- Listado de lockers
- Alta de lockers
- Eliminación de lockers
- Reactive Forms
